# COMPONENT GUIDELINES

## Component Philosophy

Components should feel:

* elegant
* calm
* intentional
* premium
* restrained

Avoid:

* excessive decoration
* repetitive card layouts
* overuse of borders
* playful SaaS styling
* noisy UI patterns

Luxury comes from:

* spacing
* typography
* rhythm
* restraint
* composition

Not from excessive effects.

---

# Layout Philosophy

Avoid making every section feel boxed.

Prefer:

* open layouts
* layered composition
* atmospheric spacing
* visual breathing room

Not every section needs:

* cards
* containers
* visible borders
* background patterns

Whitespace is part of the design.

---

# Border Radius System

Default radius:
6px

Large surfaces:
8px - 10px max

Avoid:

* oversized rounded corners
* bubble UI
* excessive pill shapes

Luxury editorial interfaces should feel:

* sharp
* clean
* controlled

---

# Border Philosophy

Avoid visible borders when possible.

Prefer:

* spacing separation
* tonal contrast
* soft shadows
* hairline dividers

If borders are needed:

* use subtle opacity
* avoid heavy outlines
* maintain softness

---

# Shadow Philosophy

Shadows should feel:

* atmospheric
* subtle
* soft

Avoid:

* floating/glowing cards
* harsh elevation
* aggressive depth

Preferred shadow style:
0 4px 20px rgba(0,0,0,0.04)

Hover shadow:
0 8px 30px rgba(0,0,0,0.08)

---

# Section Composition

Avoid repetitive section stacking.

Alternate between:

* immersive image sections
* minimal whitespace sections
* editorial typography sections
* atmospheric content sections

Every section should feel intentional.

Avoid:

* repetitive rectangles
* identical spacing rhythm
* uniform layouts

---

# Typography Components

## Serif Typography

Use for:

* names
* emotional quotes
* titles
* ceremonial moments

Should feel:

* elegant
* editorial
* cinematic

Avoid:

* excessive boldness
* oversized typography dominance

---

## Sans Serif Typography

Use for:

* metadata
* labels
* supporting information
* forms
* utility UI

Should remain:

* subtle
* readable
* secondary to emotional typography

---

# Hero Component Rules

Hero sections are emotional experiences.

Hero should:

* establish atmosphere
* create emotional tone
* feel cinematic
* prioritize imagery and typography

Hero should NOT:

* overload information
* stack excessive UI
* feel like a landing page header

Avoid:

* too many decorative layers
* excessive floating elements
* visual clutter

---

# Card Rules

Use cards carefully.

Not every content block should become a card.

Cards should:

* feel spacious
* use soft depth
* remain visually quiet

Avoid:

* thick borders
* repetitive card grids
* excessive nested cards
* dashboard-style card overuse

Prefer:

* open composition
* editorial spacing
* layered hierarchy

---

# CTA Philosophy

Only one primary CTA should dominate each section.

Primary CTA:

* stronger contrast
* clearer hierarchy
* subtle emphasis
* confident typography

Secondary CTA:

* quieter
* outline or text-based
* lower visual weight

Avoid:

* multiple competing CTAs
* excessive glow
* aggressive gradients

---

# Form Components

Forms should feel:

* intimate
* calm
* premium
* lightweight

Avoid:

* corporate form styling
* heavy borders
* excessive boxed inputs

Preferred form style:

* bottom-border inputs
* subtle focus transitions
* soft typography hierarchy

---

# RSVP Component Direction

RSVP should feel:

* emotional
* personal
* warm

Not:

* transactional
* app-like
* enterprise form UI

Success states should remain:

* subtle
* elegant
* satisfying

---

# Gallery Direction

Gallery should feel:

* cinematic
* editorial
* emotional

Avoid:

* uniform grids
* template masonry feeling
* repetitive image crops

Prefer:

* asymmetrical composition
* varied image rhythm
* immersive image storytelling
* cinematic spacing

---

# Map Component Rules

Maps should feel integrated into the experience.

Avoid:

* raw iframe placement
* hard bordered containers

Prefer:

* soft embedding
* atmospheric wrapping
* elegant framing

---

# Music Control Direction

Music controls should feel ambient.

Avoid:

* floating random widgets
* overly app-like controls

Prefer:

* minimal dock
* atmospheric placement
* elegant subtle interaction

---

# Divider Philosophy

Use dividers minimally.

Preferred dividers:

* thin hairlines
* subtle dots
* elegant spacing separation

Avoid:

* decorative separator overuse
* ornate flourishes
* repetitive ornaments

---

# Mobile Component Rules

Mobile experience is priority.

Components must:

* breathe properly
* maintain readability
* avoid clutter
* preserve emotional pacing

Touch targets:
minimum 44px

Avoid:

* cramped layouts
* excessive stacking density
* oversized UI chrome

---

# Component Consistency

All components must maintain:

* spacing consistency
* radius consistency
* shadow consistency
* typography consistency
* motion consistency

Avoid introducing:

* new visual styles
* inconsistent interaction patterns
* random decorative experiments

Consistency creates perceived quality.

---

# Luxury UI Principles

Luxury UI should feel:

* confident
* restrained
* timeless
* cinematic
* emotionally composed

The interface should never try too hard.

Restraint is part of premium design.
