# DESIGN SYSTEM

## Product Direction

Premium editorial wedding invitation experience with cinematic storytelling.

The product should feel:

* elegant
* emotional
* timeless
* sophisticated
* cinematic
* premium

Avoid:

* template marketplace feeling
* generic SaaS aesthetics
* overdecorated wedding visuals
* noisy UI patterns
* trend-chasing gimmicks

Luxury should come from:

* spacing
* typography
* pacing
* restraint
* composition
* emotional atmosphere

---

# Core Principles

* Confidence over decoration
* Typography first
* Whitespace is luxury
* Motion should support emotion
* Every section must breathe
* Avoid visual noise
* Emotional pacing is more important than feature density
* Simplicity should feel intentional, not empty

# Layout Philosophy

Layouts should feel:

* immersive
* spacious
* intentional
* cinematic

Avoid:

* repetitive boxed sections
* obvious template stacking
* excessive card layouts
* uniform composition rhythm

Alternate between:

* clean whitespace sections
* immersive image sections
* editorial typography sections
* atmospheric breathing sections

Every section should feel intentionally paced.

---

# Whitespace Philosophy

Whitespace is part of the experience.

Luxury interfaces should breathe.

Avoid:

* overcrowded compositions
* dense information stacking
* aggressive section spacing
* visual fatigue

Use whitespace to:

* guide focus
* create pacing
* establish atmosphere
* enhance typography

---

# Border Radius System

Default radius:
6px

Large surfaces:
8px – 10px max

Avoid:

* oversized rounded corners
* bubble UI
* excessive pill styling

Luxury interfaces should feel:

* refined
* controlled
* intentional

---

# Border Philosophy

Avoid visible borders when possible.

Prefer:

* spacing separation
* tonal layering
* atmospheric depth
* hairline dividers

If borders are necessary:

* keep opacity subtle
* avoid heavy outlines
* maintain softness

---

# Shadow Philosophy

Shadows should feel:

* soft
* atmospheric
* restrained

Avoid:

* harsh shadows
* floating cards
* glowing UI blocks
* aggressive depth

Preferred depth:
0 4px 20px rgba(0,0,0,0.04)

Hover depth:
0 8px 30px rgba(0,0,0,0.08)

---

# Animation Philosophy

Animations should feel:

* cinematic
* subtle
* expensive
* smooth
* emotionally supportive

Motion exists to:

* guide emotion
* improve pacing
* enhance storytelling
* support atmosphere

Avoid:

* bouncing
* elastic effects
* flashy transitions
* exaggerated parallax
* theatrical movement

Preferred easing:
cubic-bezier(0.22, 1, 0.36, 1)

---

# CTA Philosophy

Only one primary CTA should dominate each section.

Primary CTA:

* stronger contrast
* slightly bolder typography
* clearer hierarchy
* subtle depth emphasis

Secondary CTA:

* quieter
* outline or text-based
* lower visual weight

Avoid:

* competing CTAs
* excessive glow
* loud gradients

---

Hero should:

* establish atmosphere
* create emotional tone
* prioritize imagery and typography

* stack excessive UI

* emotional
* memorable

# Layout Rhythm

The invitation should feel like:

* an emotional journey
* not a stacked webpage

* repetitive reveal patterns
* identical section rhythm

* alternating composition
* varied pacing
* immersive transitions

---

# Mobile Priority

Design mobile-first.

The invitation must feel premium on mobile before desktop.

Prioritize:

* readability
* touch comfort
* emotional pacing
* cinematic scrolling

Avoid:

* cramped layouts
* excessive UI chrome
* dense stacking
* oversized controls

90% of users will experience the invitation on mobile.

# Cinematic Atmosphere

The invitation should feel:

* atmospheric
* immersive
* emotionally paced
* editorial
* cinematic

Avoid:

* obvious webpage structure
* excessive UI visibility
* mechanical section transitions
* repetitive reveal behavior

The experience should feel:

* drifting
* unfolding
* emotionally guided

Not:

* stacked
* abrupt
* interface-heavy

---

# Sensory Restraint

Luxury experiences rely on restraint.

Avoid:

* animating everything
* excessive visual effects
* constant motion
* over-layered textures
* aggressive interaction feedback

Stillness is part of the atmosphere.

Negative space and quiet moments are intentional.
