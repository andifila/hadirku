# Animation Rules

## Core Motion

Fade Up:
opacity 0 -> 1
y 24 -> 0

Hover:
scale 1.02

Tap:
scale 0.97

---

# Motion Timing

Fast interaction:
0.18s - 0.24s

Standard reveal:
0.4s - 0.6s

Cinematic transitions:
0.7s - 1s

Avoid:

* overly slow transitions
* dramatic delays
* theatrical pacing

---

# Preferred Easing

Luxury easing:
cubic-bezier(0.22, 1, 0.36, 1)

Use for:

* section reveals
* hero transitions
* modal appearance
* cinematic motion

Standard easing:
ease-out

Avoid:

* bounce easing
* elastic easing
* overshoot animations

---

# Motion Philosophy

Motion should:

* guide emotion
* support storytelling
* feel expensive
* remain subtle
* create atmosphere
* improve pacing

Avoid:

* bouncing
* aggressive scaling
* flashy motion
* over-animated decorative effects
* gimmicky transitions

Preferred motion:

* fade
* reveal
* cinematic parallax
* soft easing
* layered transitions

---

# Scroll Philosophy

Scrolling should feel:

* smooth
* cinematic
* uninterrupted
* immersive

Avoid:

* sudden snapping
* excessive scroll hijacking
* aggressive sticky sections
* parallax overuse

Parallax should remain:

* atmospheric
* subtle
* secondary to content

---

# Stagger Animation

Use stagger carefully for:

* hero typography
* gallery reveals
* RSVP success states
* cinematic entrances

Preferred stagger:
0.04s - 0.12s

Avoid:

* exaggerated cascading
* theatrical sequencing
* long delayed animations

---

# Hover Hierarchy

Primary CTA:

* stronger hover feedback
* subtle lift
* soft shadow increase

Secondary CTA:

* minimal hover
* opacity transition
* border transition

Decorative elements:

* avoid unnecessary hover effects

---

# Section Transition Philosophy

Sections should feel connected.

Avoid:

* obvious block separation
* repetitive reveal patterns
* disconnected pacing

Prefer:

* atmospheric continuity
* layered transitions
* soft visual rhythm
* immersive flow

---

# Motion Restraint

Not every element should animate.

Avoid animating:

* every card
* every text block
* every icon
* repetitive decorative elements

Stillness is part of luxury design.

Motion should feel intentional, not constant.

---

# Gallery Motion Direction

Gallery animations should feel:

* cinematic
* emotional
* editorial

Prefer:

* slow reveal
* soft zoom
* depth movement
* atmospheric transitions

Avoid:

* aggressive hover zoom
* dramatic rotation
* fast slideshow effects

---

# RSVP Motion Direction

RSVP interactions should feel:

* intimate
* calm
* elegant

Focus on:

* smooth focus transitions
* subtle success states
* gentle interaction feedback

Avoid:

* loud success animations
* aggressive CTA motion
* app-like interaction behavior

---

# Mobile Motion Rules

Mobile motion must remain:

* smooth
* lightweight
* responsive

Reduce:

* parallax intensity
* layered motion complexity

Prioritize:

* clarity
* smooth performance
* touch responsiveness

# Atmospheric Motion

Motion should feel:

* atmospheric
* emotionally guided
* cinematic
* restrained

Avoid:

* constant movement
* repetitive reveal patterns
* mechanical fade-up behavior
* obvious UI transitions

Motion should feel:

* natural
* drifting
* immersive

---

# Opacity Reveal Philosophy

Prefer opacity-based reveals over repetitive vertical motion.

Opacity-only reveals feel:

* atmospheric
* cinematic
* editorial

Avoid:

* every section sliding upward
* predictable reveal choreography
* repetitive motion semantics

Movement should remain selective and intentional.

---

# Motion Contrast

Not every element should move equally.

Create rhythm through contrast:

* moving elements
* still elements
* delayed elements
* atmospheric transitions

Stillness creates tension and sophistication.

---

# Attention Choreography

Motion should guide visual attention intentionally.

Users should:

* absorb one focal point at a time
* experience visual pacing naturally
* feel emotionally guided through scrolling

Avoid:

* competing animations
* simultaneous focal motion
* overwhelming transitions

---

# Cinematic Scroll Behavior

Scrolling should feel:

* continuous
* immersive
* emotionally paced

Avoid:

* webpage-like section reveals
* abrupt transitions
* excessive snap behavior

Transitions should feel:

* layered
* drifting
* atmospheric
